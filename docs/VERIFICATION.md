模型与抖音均使用模拟响应。自动覆盖：

- 固定账号和作品归属、发送前重核验、拒绝无效目标及 19 位数字 ID 的精度损失。
- 结构化回复/@、向大肥鱼提问的决策契约、跳过本人及空文字、固定人格输入与输出校验。
- 历史评论分轮、分页停滞、分页上限和续扫、子回复独立去重、重启恢复。
- 每轮发送上限、发送间隔、独占锁、旧锁不自动抢占。
- 模型不能改账号/作品/评论目标、列表外素材拒绝、关闭表情不加载依赖。
- 发送超时/回执缺失/目标未确认/图片未附上时进入 unknown，不自动重发。
- 两家模型请求格式、缺密钥/错误JSON/拒绝/截断/超时，不回显服务响应体或密钥。
- 真实 neko 包自带索引可离线查到素材；这一项禁止网络，不下载 GIF。
- pending 触发快照刷新、关闭关系开关后的旧积压保护、生成前后证据复核。
- 已确认历史本人回复回填、真实 normalizer 的根回复组合、子回复独立去重、未确认关系不猜目标。
- 回执作者错配或缺失、入站时间统一毫秒、确定未发送与未知结果的分类和恢复。
- 直接父链与稳定匿名发言者、已知向其他观众说话的反证；扫描、任务和游标的事务回滚。
