# 本地控制台验收

本轮已确认范围：单页配置与日志工作台、只读状态检测、执行一轮／开始轮询／停止、分级完整日志与对话记录、直接呼唤角色名触发，以及 macOS／Windows 一键入口。继续使用油猴、本人账号、手动作品列表和现有 SQLite 去重账本。

实现与自动验证不代替用户手动验收。本轮暂不 commit／push。下列真实发送步骤由用户准备好后执行；开启网页或点击「检测状态」不应发布评论。

## 启动和首次连接

1. macOS 双击 `start.command`，或在项目目录运行 `npm run launch`。没有 Node.js 时应给出安装要求；不得自动下载 Node.js 或修改 npm 全局配置。
2. 首次缺少依赖时使用锁文件安装，并保留 optional 平台依赖；缺少／更新前端时构建。依赖和构建均有效时再次启动不重复安装、构建。
3. 浏览器打开本地控制台。尚未安装或启用油猴时，状态应说明如何接通；页面不应显示虚构在线状态。
4. 安装页面提供的油猴脚本，启用 Chrome「允许用户脚本」，通过「复制配对 Token」配对并刷新已登录的抖音页面。
5. 已有同项目控制台运行时，再双击只打开现有页面；同端口是其他服务时给出冲突提示，不结束或覆盖该服务。

## 配置和只读检测

| 条目 | 场景 | 预期 |
| --- | --- | --- |
| AC1 配置读取 | 首次打开或刷新页面 | 显示现有 UID、作品、模型、轮询、表情和呼唤配置；现存密钥不回显 |
| AC2 保存配置 | 停止时输入合法配置并保存，再刷新 | 配置保持一致；密钥空白保留已有值；保存不启动轮询或发布评论 |
| AC3 无效／冲突输入 | 数字型长 ID、非法链接、零间隔；外部编辑后使用旧页面保存 | 明确报错或提示配置版本冲突，不静默覆盖已有配置 |
| AC4 运行中配置 | 轮询期间尝试修改影响发送的配置 | 提示先停止；显示当前实际运行状态，不假装配置已热更新 |
| AC5 状态检测 | 浏览器未连接、换号、非本人作品、缺密钥 | 每项独立给出状态、原因和检测时间；不调用模型、不发布评论 |
| AC6 模型状态文案 | 填入密钥但未发送模型请求 | 只显示已配置／未配置，不将其称为模型 API 已验证 |

状态检测应覆盖 Bridge 可达、油猴连接／最近心跳、实时 UID 与配置 UID、一条条作品归属、密钥配置、Worker 状态与回复／@关系是否已确认。单项失败不应导致其余检查项消失。

## 日志和对话记录

1. 默认对话记录展示「评论原文 → AI 回复 → 结果」，跳过、失败、待核查也可见，且显示具体原因。
2. 切换完整日志，查看扫描、触发判断、模型调用与生成、等待、表情处理、发布和回执等阶段。同一任务的两种视图状态须一致。
3. 按最低级别 `DEBUG / INFO / WARN / ERROR`、关键词筛选，展开受限诊断详情，导出文本或 JSONL。密钥、Bridge Token、Cookie 和认证头不得出现在列表、详情或导出中。
4. 长评论可展开；正在阅读旧记录时关闭「跟随最新」，新日志不应强行滚动页面。刷新／重启后可查询已落盘日志。
5. 原有任务没有完整阶段日志时，显示已保存的终态和原因，标记历史记录，不伪造过去的步骤。
6. `unknown` 显示「待核查」，与明确失败区分；不提供直接重发按钮。
7. 在对话页导出文字时包含评论、AI 回复、状态和原因，并说明仅导出当前已加载的筛选结果；完整日志页导出的是分阶段运行事件。

## 用户准备好后的真实发送

先选一个自己的测试作品，保持表情关闭、每轮上限为 1，确认检测显示账号与归属一致。

1. 用另一个账号单独留言「大肥鱼」或「大肥鱼！」，点击「执行一轮」。日志应显示直接呼唤触发、生成结果和发布核验结果。普通讨论中包含“大肥鱼”仍需上下文判断；自己的评论不触发。
2. 在抖音页面确认回复作者、实际目标评论和内容。历史上仅因纯呼唤被跳过的评论可以因新规则重新评估；已成功或待核查的目标不能因此重开。
3. 再次执行一轮，同一目标不重发；刷新页面、切换日志和保存配置也不能解除去重。
4. 点击「开始轮询」，观察至少两轮、下次扫描时间、每轮数量和发送间隔。连续点击启动或并行点击执行一轮不得创建第二个 Worker。
5. 点击停止，先显示停止中，等在途步骤结束后显示已停止；明确尚未发送的任务应回到待处理，下次启动可继续。已经提交的请求仍按回执保存成功或待核查，不能把停止解释成撤回。外部 CLI 占锁时网页应显示占用，不强行杀进程或删除锁。
6. 保留 `inboundSchemaConfirmed: false`，直到已有回复／@正反例已对照网页确认；最后再单独验收表情图片权限、GIF 动画和不同客户端显示。

## Windows 实机补充

macOS 上的测试只能验证 `.bat` 内容、命令构造、含空格／中文路径和共享 Node 启动逻辑。以下项目仍须 Windows 实机确认，不能以 macOS 自动测试宣称通过：

- 双击 `start.bat` 后可定位项目目录；建议将项目放在含空格、中文的路径中覆盖验证。
- Node.js／npm 缺失或版本过低时提示可见；失败后窗口暂停，便于读取原因。
- 首次 `npm ci --include=optional`、better-sqlite3 原生模块和 Vite 的 Windows 平台依赖能够加载。
- 默认浏览器能打开本地网页，Chrome 油猴可连接 Bridge。
- Ctrl+C 可停止本服务并等待收尾；强制关闭窗口／任务管理器结束进程不承诺优雅退出，重启时仍应遵循发送中任务转待核查的规则。
